GA4 setup and export
  1. In GA4 Admin, under Custom definitions, add event-scoped dimensions for personality, share_source and share_method.
  2. In Explore, create a Free form exploration. Add the dimensions Event name and Personality, and the metric Event count.
  3. Filter Event name to begin with quiz_. Put Event name and Personality in Rows and Event count in Values. Set Show rows to 500.
  4. Export as CSV and load it above.
